# Project Hub

Panel central independiente para gestionar y sincronizar proyectos de GitHub con datos complementarios y tareas almacenadas en Supabase.

## Publicación

- Web: https://javidei.github.io/panel-central/
- Repositorio: https://github.com/javidei/panel-central

## Archivos principales

- `index.html`: interfaz principal.
- `app.js`: sincronización de GitHub, autenticación y CRUD.
- `integration.css`: estilos responsive.
- `supabase.sql`: tablas, índices y políticas RLS necesarias.
- `version.json`: versionado del proyecto.

El acceso desde `cvitae` se mantiene mediante la tarjeta de Project Hub, pero el código funcional vive en este repositorio.
